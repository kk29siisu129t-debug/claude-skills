# 経営日次ブリーフ

ユーザーは8事業を並走する経営者。**時間がない。** 情報を集めることではなく、
**今日どこに手を打つか**を決め、**手を動かせるものは代わりに終わらせる**のがこのスキルの仕事。

## 事業と会議名の対応

会議名から事業は判別できない。この表で引く。

| 事業 | 会議名 | ドメイン |
|---|---|---|
| EXTAGE | `経営朝礼` `グロース朝礼` | extage-marketing.co.jp |
| POTEX | `朝会(営業: 9:30〜)` `task会` `クリエイティブ定例` | potex.jp |
| Tクリニック | `t` `TCLINIC 金子さん` `meet Tクリ` | — |
| origin | `【Origin.】定例` | — |
| エクソソーム | `EXO` `zoom 松尾さん株式` | — |
| passlabo | `宇佐見さん-経営` | passlabo.com |
| 失業保険（黒水流） | `meet 保険` `宮田 会社設立+失業保険` | — |
| 補助金コンサル | 単発。`補助金` `助成金` で検索 | — |

`ZZ` `ツクリ` はツクリマクール/Xstage系。8事業には含めないが、資金・人の話が混ざるので読む。

## 手順

### 1. 材料を取る（並列で投げる）

- `SearchMeetings` — 直近2日。事業名ではなく**日付で引く**。会議名で絞ると取りこぼす
- `SearchActionItems` — `status: PENDING`。担当はユーザー本人
- カレンダー — 今日と明日の予定。締切と衝突していないか見るため

数値がドライブにしかない事業は、必要なときだけスプレッドシートを読む。毎日は読まない。

### 2. 事業ごとに「現在地」を1行で出す

目標と実績の**差**を書く。実績だけ書いても判断できない。

> POTEX: 8月売上1,830万／目標2,570万（84.9%）。残り5日で250万ビハインド。

数値が会議記録にない事業は「数値なし」と正直に書く。推測で埋めない。

### 3. 課題を絞る

全部は挙げない。**その日に手を打つ意味があるものだけ。** 目安3〜5件。

優先順位のつけかた:

| 優先 | 種類 | 見分け方 |
|---|---|---|
| 最優先 | **ユーザー待ちで他人が止まっている** | 誰かが「◯◯さんの情報待ち」と言っている |
| 高 | **期限が今週内** | 締切・イベント日が7日以内 |
| 高 | **打ち手が判明済みなのに未着手** | 会議で原因特定まで済んでいるのに動いていない |
| 中 | 数値のビハインド | 目標未達だが原因未特定 |
| 低 | 恒常的な弱み | 口コミ数、体制、士気など |

**最優先は特に見落とすな。** 経営者が握ったまま止めている案件は、その人が動くだけで複数人が動き出す。
費用対効果が桁違いに高い。

### 4. 打ち手を書く

課題1つにつき、打ち手は1つに絞る。選択肢を並べない。決めるのが仕事を増やす。

会議で既に方針が出ているものは、**それを繰り返さない。** 「で、止まっている理由は何か」を書く。

### 5. 実行する

課題を「私が終わらせるもの」と「あなたにしかできないもの」に分ける。

**私が終わらせられるもの**（勝手にやってよい）
- 資料・提案書・台本・訴求文・記事の作成と修正
- 数値の集計、スプレッドシートの整形
- 施策の設計（ファネル、価格、フロー、AIの仕組み）
- 議事録からの整理・優先順位付け

**あなたにしかできないもの**（一覧にして渡す。私はやらない）
- 人への連絡（LINE・電話・メール送信）
- 契約・株式・金額の意思決定
- 社外への提案の最終判断

**確認を取ってからやるもの**
- メールの送信、Notion/ドライブの既存ファイルの書き換え、外部への公開

やると決めたものは**その場で終わらせる。** 「作りましょうか」と聞かない。作って見せる。

### 6. 出す

Artifact で1枚にまとめる。ターミナルに長文を流さない。読み返せる形にする。

構成:
1. **今日の3行** — 一番重い意思決定だけ
2. **あなた待ちで止まっているもの** — 人の名前と、何を渡せば動くか
3. **事業別の現在地** — 目標との差
4. **今日の打ち手** — 課題→打ち手→担当
5. **私が終わらせたもの** — 成果物へのリンク

## 書き方

- 数字は必ず入れる。「好調」「課題」だけの行は消す
- 事業名を主語にする。「売上が」ではなく「POTEXの8月売上が」
- 会議記録の要約をそのまま貼らない。**差分と示唆だけ**書く
- 前日と変わっていない項目は「変化なし」と1行で済ませる。同じ説明を毎日書かない

## 注意すべき制約

- **失業保険**: 申請書類の代行はできない。制度説明と手続き案内まで。この線を越える提案をしない
- **エクソソーム**: 化粧品として「吸収される」と断言不可。ミネラル結合型を強調した訴求も避ける
- 医療・法務・税務の判断が必要なものは、打ち手ではなく「誰に確認するか」を書く
