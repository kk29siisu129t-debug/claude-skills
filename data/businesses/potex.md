## 一番の課題は継続率（2026-09-01 代表確認）

**目標50%に対して実績5〜6%。**代表が「POTEXで一番の課題」と明言。

数字（朝会 2026-09-01）:

| | |
|---|---|
| 8月継続率 | **5〜6%** |
| 分母 | 卒業20名 |
| 成約 | 1件。高確度2件を足しても最大20% |
| 8月着地 | 成約72件・売上¥29,800,400・顧客単価¥402,815（竹目標¥3,000万の99.3%） |
| 9月目標 | 竹¥3,485万 / 松¥4,368万。契約単価¥420,000・予約率 竹21.67%/松24% |

**分母が20名しかない。**月次では1〜2件動くだけで継続率が10ポイント跳ねる。
月次の増減を成果と読むと誤る。四半期の累計で見る。

打ち手は3方向で同時に走っている:

1. **継続プランの設計変更** — コーチが頭出しする運用をやめ、アフターフォローセッションで
   石島さんが一元案内。毎日FB＋月1コーチングの新プラン（3ヶ月¥180,000 / 6ヶ月¥290,000）
2. **AIで毎日のFB** — 新川さんが構築。代表の言葉で「当初目標より高いボールを投げ続ける」
3. **コミュニティ** — 10月オフラインイベントを「継続率向上→参加者数増加」から逆算（木曜打合せ）

**目標50%は代表の口頭。**記録上は「継続率の目標は石島さんとすり合わせて次回朝会で共有予定」
の段階。次回朝会で確定値を取ること。

### 記録の矛盾（2026-09-01 時点）

8/31朝会は「竹目標¥3,000万を106.6%で超過着地（¥29,800,400）」と書いているが、
¥29,800,400 は ¥3,000万 を下回る。9/1朝会の「ほぼ到達」が正しい（99.3%）。
**8/31 の達成率は使わない。**

## 審査不合格4割と、低単価フロント商品（2026-09-02 代表指定・優先度高）

**体験予約の約4割が審査で不合格。**集客した人の4割に、売れる商品が無い。

**審査基準は下げない**（採用定例 2026-08-30 で全員確認済み。下げるとコーチ負荷と継続率に跳ね返る）。
**下げずに受け皿を作る。**それが SHElikes のような低単価商品。

### すでに一度、保留になっている

> フロント商品（SHElikes的な低単価サービス）の設計は有望だが、
> **カリキュラム作成が先決**で商品設計は慎重に進める必要がある
> — task会 2026-08-20

**この「カリキュラム作成が先決」が半月止めている。**
既存カリキュラムの一部切り出しで始めれば、新規作成は要らない。

Under 25プラン（8/15開始・契約者5人）は**年齢での切り分け**であって、
**単価と難易度での切り分けではない。**審査不合格者の受け皿にはならない。

### 決めること

1. **誰に売るか**を1行で — 審査不合格者／単価に届かない層／両方
2. **価格帯** — 既存の顧客単価 ¥402,815 に対していくらか
3. **カリキュラム** — 既存の一部切り出しで始めてよいか
4. **審査不合格者への案内動線** — 今は落ちたら終わりで、次の案内が無い

### 重要度の出方について

POTEX の優先順位は 満足度＞採用＞売上 で、売上の重みが 1.0。
**この2件は売上の課題なので、計算上の重要度は 1.3 前後にしかならない。**
重みを勝手に変えず、`pin`（代表指定）を付けて一覧の先頭に出している。
**重み自体を変えたい場合は、その旨を言うこと。**
