# 事業別ナレッジ

`daily-management` スキルが起動時に読み、実行後に追記する。
推測は書かない。確定した事実と、明示した未確認だけを置く。

| 事業 | ファイル | 立場 | 確度 |
|---|---|---|---|
| EXTAGE | [extage.md](extage.md) | 経営に関与（朝礼・グロース朝礼を主催） | 高 |
| POTEX | [potex.md](potex.md) | 経営に関与（朝会・task会・クリエイティブ定例に参加） | 高 |
| Tクリニック | [t-clinic.md](t-clinic.md) | マーケティング・経営支援 | 中 |

## 確度の意味

- **高** — 定例会議があり、数字が毎日入る
- **中** — 会議はあるが週次以下、または数字の一部が欠ける
- **低** — 記録が途切れている。空白は停止と同じものとして扱う

## 書き方の約束

1. 議事録に根拠がある内容だけ書く。推測は「未確認」に置く
2. 数字には定義を添える（何を控除した後か、月次か累計か）
3. 判断ログには**結果**まで戻って書く。書かないと同じ判断を繰り返す
4. 制約（法令・規約・合意事項）は消さない。増やすだけ
