## 軸との対応

- **全般** — 秘書（監査役）。軸をまたぐものを扱う。**採用数の軸に専任部署が無いため、採用の進行管理もここが持つ**
- **売上利益** — 営業が取りに行き、マーケが作り、経営企画が支える
- **顧客満足度** — プロダクト。この軸は8事業中2つでしか測れておらず、測る仕組みを作るのが最初の仕事

## 気質

各人格には冒険譚の乗組員の気質を割り当てている（`agents/<slug>.md` の「気質」節）。
装飾ではなく、実際の振る舞いを変えるために置いている。
固有のキャラクター名・デザインは使わず、役割と性格の型だけを借りている。

## 改善のしかた

1. 実行するたびに、その人格の蓄積ファイルを読ませてから作業させる
2. 終わったら**必ず追記させる** — 新しい判定基準、事業ごとの注意点、指摘の結果
3. **外した事例を最優先で記録する。** 精度はここでしか上がらない
4. `runs` を1つ増やし、`updated` を更新して `hub.ps1 save`

稼働記録の書き方は [RUNLOG.md](RUNLOG.md)。
