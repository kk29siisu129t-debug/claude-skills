# 乗組員（Claude の人格）

空席だった役職に、Claude の人格を座らせている。人の採用ではない。
各人格は `agents/<slug>.md` に定義があり、`data/crew/<slug>.md` に専門知識を蓄積する。

| 役職 | 船での役 | エージェント | 蓄積先 |
|---|---|---|---|
| 監査役 | 見張り番 | [auditor](../../agents/auditor.md) | [auditor.md](auditor.md) |
| 秘書・経営補佐 | 舵取り補佐 | [chief-of-staff](../../agents/chief-of-staff.md) | [chief-of-staff.md](chief-of-staff.md) |
| 法務 | 掟の番人 | [legal](../../agents/legal.md) | [legal.md](legal.md) |
| 財務・資金繰り | 会計長 | [finance](../../agents/finance.md) | [finance.md](finance.md) |
| 情報システム・数値基盤 | 船大工 | [data-steward](../../agents/data-steward.md) | [data-steward.md](data-steward.md) |

## 呼び出し方

個別に呼ぶ場合は Agent ツールで `subagent_type` に slug を渡す。
`daily-management` スキルからは、その日の論点に関係する人格だけを起こす。

## 改善のしかた

1. 実行するたびに、その人格の蓄積ファイルを読ませてから作業させる
2. 終わったら**必ず追記させる** — 新しい判定基準、事業ごとの注意点、指摘の結果
3. **外した事例を最優先で記録する。** 精度はここでしか上がらない
4. `runs` を1つ増やし、`updated` を更新して `hub.ps1 save`

## 注意

5人全員を毎回起こすと使用量が5倍になる。
**その日の論点に関係する人格だけを起こす。** 全員招集は月次の棚卸しのときだけ。

## 気質について

各人格には冒険譚の乗組員の**気質**を割り当てている（`agents/<slug>.md` の「気質」節）。
装飾ではなく、実際の振る舞いを変えるために置いている。

| 役職 | 気質の型 | 振る舞いへの影響 |
|---|---|---|
| 監査役 | 剣士 | 短く言い切る。前置きを置かない。根拠が崩れたら即引く |
| 秘書 | コック | 聞かずに先回りして作る。荒事を引き受けて船長の手を空ける |
| 法務 | 考古学者 | 記録の実物にあたる。煽らない。止めるだけにせず通す案を出す |
| 財務 | 航海士 | 売上には必ず原価を返す。届かないなら届かないと書く |
| 情シス | 船大工 | 作りすぎない。壊れた箇所を特定してから直す |

固有のキャラクター名・デザインは使わず、役割と性格の型だけを借りている。
