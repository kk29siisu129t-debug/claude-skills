   → **料金表だけ直しても継続率は動かない可能性が高い。**（9/23 稲川「料金設計以前の問題」）

## 4. 継続を妨げている設計要因（会議で指摘済みのもの）

### A. 継続の「打診の場」の設計
| 要因 | 出典 | 対応状況 |
|---|---|---|
| コーチが頭出し→担当変更で心理的ハードル上昇 | 8/31 | コーチ打診を停止し、AFS営業担当に一元化（**済**） |
| 最終回で「ありがとうございました」と締めた後にAFSへ誘うのはハードルが高い | 9/17 | AFSを**最終回の1回前**に移す（合意・周知中） |
| AFSの位置づけ・名前が弱い | 9/17 | 「未来戦略会議」等に改名検討（有田さん） |
| AFSの離脱理由はコーチとの関係性が多い | 9/23 | 未着手 |

### B. 本商品の中で「先」が見えていない
| 要因 | 出典 |
|---|---|
| 3ヶ月後・半年後にどうなっているかのイメージが具体的でない | 10/4 |
| POTEXが目指す「理想の受講者像」がふわっとしており、コーチもクライアントも目指す先を共有していない | 10/4 |
| 中間地点のギアアップセッションが体系化されていない（コーチが流れでやっている） | 10/4 |
| 月次レポートの運用基準（4・8回目後 or 月末）が未確定 | 9/23 |
| 成長を可視化するレベル・称号・スキルツリーが無い | 9/23・10/4 |

### C. 誰に売っているか
| 要因 | 出典 |
|---|---|
| 継続しやすいのはキャリア・転職・事業・SNSなど**実利が伴う層**。ふわっとした目標の人は継続イメージが湧きにくい | 10/1 田原さん |
| カウンセリング寄り（「お守り的な安心感」）も継続しやすい | 10/1 |
| 「コーチング」という言葉が実態（コンサル込み）とずれ、顧客の要求水準を下げている | 9/23 |

### D. 提供品質
| 要因 | 出典 |
|---|---|
| コーチ34名中 Dランク相当13名・C以下17名 | 8/30 |
| コーチ歴が長くキャパも多いのに継続ゼロのコーチがいる | 10/1 |
| コーチ交代が起きにくい（手放すインセンティブが無い） | 10/4 |
| アンケート回収率 10〜30%で、満足度をそもそも測れていない | 10/1 |

### E. 商品構造そのもの（推測を含む）
- **マスターのコミュニティ無期限特典**は「一生涯フォロー」のメッセージとして維持（9/9）。
  一方で、卒業後もコミュニティに残れるなら**継続プランに払う理由が1つ減る**。継続プランとの役割分担が記録に無い。（推測）
- 旧継続プランのFBは本商品より薄い（2日に1回）。**継続すると体験が下がる**設計になっている。

## 5. 設計変更で決めること

今日（10/4）の対面で詰める予定だったもの＋上の要因から。

1. **継続プランの中身と価格を1案に決める** — 梅竹松それぞれのセッション回数・FB頻度。9/1案（3ヶ月18万）との関係
2. **継続率の定義** — 分母を卒業者全員に固定するか
3. **AFSの位置と名前** — 最終回の1回前への変更を全コーチ一律で始める日付
4. **本商品の中間に「ギアアップセッション」を固定アジェンダで入れるか** — 月次レポートと同じタイミングにするか
5. **継続前提で売るか** — 営業時に「3ヶ月で仕組み、6ヶ月でコンサル」（8/31）のように、卒業後の段まで最初から見せるか
6. **マスターの無期限コミュニティと継続プランの役割分担**
7. **ペルソナを実利層に寄せるか** — 寄せると成約数が減る可能性がある。売上とのトレードオフ
8. **コーチ交代の仕組み** — 目標が変わった時に交代を当たり前にするか

**優先順位の提案**：③（今週打てる）→ ②（効果を測るため）→ ①④⑤（商品設計の本体）→ ⑥⑦⑧（上流の判断）。
田原さんの優先順位（9/23）は「商品設計 → コーチ養成講座 → 月次レポート」。
