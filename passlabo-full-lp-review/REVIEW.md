## 構成（ストーリー改修 d84d83d 以降。旧版の HTML は out/archive-07664ea/ に保存）
固定 FV → 目標「目指すのは、時間内に解き切ること。」→ 共感「時間が足りない。点数が上がらない。」→ 転換「解く量だけでなく、解き方にも、目を向ける。」→ 講義で扱う3つ（時短戦略・思考法・問題の取り組み方）→ 実際の板書と配布テキスト → 講師（地方の公立高校から、東大医学部へ）→ 講義参加者の特典 → 無料講義と最終 CTA → フッター。
- 会議要約（ユーザー確認済みの Circleback 会議の要約メール）に沿い、受講で目指すことを FV の直下に置き、悩みは「時間が足りない」「点数が上がらない」を軸に、原因名ではなく受験生に起きる結果と気持ちで書いた。成果・点数の保証や「90点以上」などの数値は入れていない。
- 各セクションの末尾に、次を読む理由になる短い橋渡しを置いた（例:「では、どこから見直せばいいのか。」）。演習の価値は否定せず、量との優劣・原因の断定はしない。
- 3つのテーマは「考える観点」（読み手の問い）と「講義では」（講師の手元・板書を見せながら解説する＝原典画像 06）を分けた。観点の文は読み手への問いで、講義内容の細目・時間配分・解く順番の約束ではない。

- 参照（FWH・POTEX・作品設計ブートキャンプ）からは構成とリズムの考え方だけを借り、作品・作字・人物・実績・固有の体験談は使っていない。参照画像は LP に埋め込んでいない。

## 演出と追従 CTA（src/sections.mjs）
- 演出は3つだけ、各1回: 転換の「目を向ける。」に下線が走る（0.55s）／3テーマが 0・100・200ms ずれて現れる（0.45s）／板書と教材が 12px 浮上する（0.5s）。常時動く演出・カウントアップ・スクロール固定は無い。
- 内容は最初から HTML にある。JS が動かない・prefers-reduced-motion: reduce のときは演出なしで全文表示。素早く通り過ぎた要素も表示状態にする。
- SP（900px 未満）の追従 CTA: FV の CTA が画面外に出た後だけ表示。通常の CTA が画面にあるとき、最終セクション〜フッターでは隠す。safe-area を含む下余白、表示中は scroll-padding-bottom でフォーカス先を覆わない。追従 CTA も確認用 type=button。
- JS はこの1本だけ（外部取得なし）。CSP は FV のものに、そのスクリプトの sha256 だけを script-src として追加（form-action 'none' のまま）。
