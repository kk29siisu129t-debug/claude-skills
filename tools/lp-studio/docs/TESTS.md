## 2. v1 → v2 対応表

扱いの意味: **統合** = 別のテストに同じ検査が入った / **移行** = v2 の仕組みで同じ性質を確かめる形に書き換えた / **削除** = 機能自体が v2 で無くなった。

## 4. 未カバー・弱くなった点

2. 取り込んだ JSON の確認日が実在しない日付（例 2026-02-30）なら未検証に戻すこと。schema.js に処理はあるが未テスト。
