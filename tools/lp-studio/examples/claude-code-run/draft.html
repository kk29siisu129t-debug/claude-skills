テキストを開いたまま、手が止まっていませんか

教材は買ったが、平日の夜に何から手をつけるか決められず、週末にまとめてやろうとして崩れる

帰宅後、前回どこまで進んだかを思い出すところから始まる
平日に遅れた分を週末に取り返そうとして、週末ごと崩れる
このペースで間に合うのか、自分では判断がつかない

止まる理由は、意志の弱さより「段取りの空白」にあるのかもしれません

疲れている夜ほど、何をやるかを決めること自体が重い負担になります。決める作業を先に済ませておけば、夜は手を動かすだけで済みます。

これまで

  • その日の気分で範囲を決める
  • 遅れたら週末にまとめて取り返す
  • 計画は最初に一度だけ立てる

これから

  • 毎晩15分で終わる単位に分けておく
  • 遅れは翌週の計画で吸収する
  • 週ごとに計画そのものを見直す
