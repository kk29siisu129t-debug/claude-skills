# POTEX キャリアを考えるための自己理解（apps/potex-bigfive）

いまの自分の骨格（考え方や動き方の傾向）を簡易分析で振り返り、希望する働き方・関心のある職能・
これまでの経験を整理して、**キャリアの解像度を上げる** ための、スマートフォン縦画面ファーストのツールです。
POTEX の支援の使い方は、その後の任意のステップとして本人が選びます。

ここでいう「骨格」は、変わらない本質を決めつけるものではなく、**いま時点の自己理解** として扱います。

> **公開デモです。本番運用ではありません。**
> 相談・予約・申し込みにはつながっていません（相談窓口は「準備中」と表示します）。

## このツールがしないこと

- 性格の結果から、職種・職業の向き不向き、キャリアの道すじの候補、採用可否を判定しない
  （性格の結果は、働き方や学び方を考える問いにだけ使う。職種候補の点数づけや足切りにも使わない）
- 実際の昇進予測、適性保証、資格・採用評価をしない。キャリアの道すじは本人が比べるための「例」
- 退職や契約など、大きな決断を勧めない。副業・独立を全員の目標として扱わない
- 年齢・収入・健康の情報、名前・メール・電話を集めない。自由入力欄もない。社名を推薦しない
- 性格の結果だけから、プラン・価格・入会可否・成果・解約の見込みを判定しない
- 支援の使い方の案を、性格スコアで並べ替えたりおすすめしたりしない（並び順は固定）
- 高額プランへの誘導、リードスコア、採用・医療・教育の選抜判定をしない
- 固定タイプ、優劣、正常／異常、IQ、人口との比較（上位○％・平均以上など）、偽の信頼区間を表示しない

成約率・継続率・満足度の向上は、事業上の **仮説** です。このツールの効果として実証されたものではありません。

## 画面の流れ

1. トップ「キャリアを考えるための自己理解」（分析を飛ばしてキャリアの整理へ、または POTEX の支援の使い方へ進むこともできる）
2. はじめる前に（免責・プライバシー・出典）
3. 20問の簡易分析（4択。押すとすぐ次の質問へ進む。前へ戻る、進み具合、回答一覧からの再編集）
4. 結果（5観点の連続値 1〜4、働き方と学び方を考える問い、不確かさの説明）
5. キャリアの整理（希望する働き方、関心のある職能、職能ごとの経験と根拠の種類の自己申告。すべて選択式・任意）
6. キャリアの道すじの例（3つを常に表示。暫定の主候補1つと比較候補2つ。今週まず試すこと1つと、いつ振り返るかを選ぶ）
7. まとめ（暫定の道すじ・今週試すこと・振り返る時期を、本人が行う行動文として表示）
8. POTEX の支援の使い方（任意）: 目標と希望の整理 → 支援の使い方の3案 → 最初の小さな行動 → まとめに追加

画面上部の「やり直す」で、回答・結果・キャリアの選択・道すじと試すこと・POTEX の選択をすべて消します。

## キャリアの整理と道すじの例

### 選ぶもの（すべて選択式・任意）

| 項目 | 選択肢 |
|---|---|
| 希望する働き方（1つ） | 事業づくりや独立も検討したい／組織の中で経営の責任を広げたい／専門性を深めたい／まだ決めない |
| 関心のある職能（複数） | 課題整理・企画／提案・営業／実行・プロジェクト推進／分析・改善／専門技術 |
| 経験（職能ごとに1つ） | 未経験／学んだ／支援付きで実施／自力で実施し、成果を説明できる |
| 根拠の種類（職能ごとに1つ） | 学習作品／仕事や活動で1回試した／複数回試した／他者から具体的なフィードバックあり／まだ根拠なし |
| 今週まず試すこと（1つ） | 道すじごとの行動と、共通の行動（事例の振り返り、公開情報の職務比較、小さな自主課題、身近な人の感想） |
| いつ振り返るか（1つ） | 1週間後／2週間後／自分で決める |

画面では次のことを明記します。
- 独立したい気持ちと独立の準備は別のこと
- 副業や独立は手段のひとつで、全員の目標ではない
- 関心は能力を示すものではない
- 自己申告は資格や採用の評価ではない

### 道すじの例（段階：入口 → 経験を広げる → 責任を担う → 長期の選択）

| 道すじ | 入口 | 経験を広げる | 責任を担う | 長期の選択 |
|---|---|---|---|---|
| A 事業づくり・独立も検討する | 企画・事業支援担当 | 事業責任者 | 経営メンバー → 創業者・代表 | 事業オーナー → 承継後の顧問 |
| B 組織の中で経営責任を広げる | 総合職・企画担当 | 課長相当 | 部長相当 → 事業部長 | 本部長・執行役員 → 顧問 |
| C 専門性を深める | 専門職 | シニア | リード／プリンシパル → チーフ・上席 | フェロー級 → 現役の専門家・顧問 |

- **暫定の主候補**: 希望する働き方から1つ決まる。「まだ決めない」や未選択のときは主候補を出さず、3つを優劣なく並べる
- **手動での変更**: 本人はいつでも、どの道すじでも暫定の主候補にしたり、「主候補を決めずに比べる」に戻したりできる。並び順は常に A・B・C で固定
- **各カードの表示**:
  - 表示している理由（希望または手動の選択）
  - 選んだ職能と自己申告とのつながり
  - まだ確かめたい点
  - 今週試せることの例
- **詳細の開閉**: 詳細は主候補のカードだけ開いた状態で表示し、比較候補は閉じて短く見渡せるようにしている
- **未定のとき**: 道すじが未定でも「まず1つ試して確かめる」を選べる
- **行き来**: 道すじの間は行き来できることを明記している（組織の中で専門性を活かす、など）
- **性格との分離**: `src/career.js` の関数は性格スコアを受け取らない。E2E で、性格の回答が違っても同じ選択なら道すじの表示がまったく同じことを確認している

## 起動・ビルド・テスト

Node.js 20 以上（確認は v22.22.0）。開発用の依存は npm 公式レジストリからのみ取得します。
アプリ本体は実行時の依存ゼロ（外部フォント・CDN なし）です。

```bash
cd apps/potex-bigfive
npm ci                # 開発用依存（eslint / typescript / playwright）
npm run build         # dist/index.html（単体で開ける HTML）と dist/artifact.html（Claude Artifact 用）を生成
open dist/index.html  # またはブラウザで直接開く。サーバー不要

npm run lint          # ESLint（保存・通信・innerHTML などを禁止するルール込み）
npm run typecheck     # tsc --checkJs（JSDoc の型検査）
npm test              # 採点ロジックと文言の単体テスト（node:test）
npm run test:e2e      # Chromium での画面テスト。スクリーンショットは test-results/screenshots/
npm run check         # 上記すべて
```

E2E は Playwright の Chromium を使います。ブラウザが未導入の環境では
`npx playwright install chromium` が必要です（このリポジトリの検証環境では導入済みのものを使用）。

## 採点

- 回答は普段の自分についての4択。画面では上から
  「当てはまる」(4)、「やや当てはまる」(3)、「あまり当てはまらない」(2)、「当てはまらない」(1)。
  中立の選択肢はない
- 未回答を初期値で埋めない。20問すべてが 1〜4 の整数であると検証できたときだけ結果を出す
  （未回答・範囲外・非整数・文字列、旧形式の 5 は拒否）
- 逆転項目は `5 − 回答`（1↔4、2↔3）
- 各因子は4項目の平均（1〜4 の連続値、0.25 刻み）を主表示
- 確認している値: 全4 → E/A/C/N=2.5, O=1.75／全1 → E/A/C/N=2.5, O=3.25／
  正4逆1 → 全4／正1逆4 → 全1／逆項目を 1→4 にすると当該因子の平均だけ 0.75 下がる

### 回答画面の操作

- 回答ボタン（4つ）を1回押すと、すぐ次の質問へ進む。最後の質問と、回答一覧からの編集では回答の確認画面へ進む
- 前の質問へ戻ると選んだ回答が表示される。同じ値を押し直しても次へ進む（「回答を変えずに次へ」もある）
- 画面が切り替わった直後の 450ms は操作を受け付けない。二重クリック・二重タップの2回目が
  次の質問の回答や、確認画面の先への移動として扱われるのを防ぐ
- Enter / Space の押し続け（キーリピート）は無視する。進んだ後はフォーカスが新しい質問の見出しに移るため、
  押し続けたキーが次の質問の回答にならない
- ラジオボタンではなく通常のボタンにしているため、矢印キーで選択が動いて勝手に確定することがない。
  キーボードでは Tab で選び、Enter または Space で確定する

| 因子（画面の名前） | 項目番号 |
|---|---|
| 外向性 | 1, 6, 11, 16 |
| 協調性 | 2, 7, 12, 17 |
| 誠実性 | 3, 8, 13, 18 |
| 感情の揺れやすさ（神経症傾向） | 4, 9, 14, 19（値が大きいほど揺れやすい方向） |
| 開放性（想像力・抽象的な関心） | 5, 10, 15, 20（知能の高さではない） |

項目の符号（正・逆）と因子記号は `src/scoring.js` の内部データにだけあり、画面には出しません。

## 尺度の出典と、独自日本語訳の制限

- 質問は Mini-IPIP の20項目を参考にした **POTEX 向けの独自日本語訳** です。
- 回答形式は原版の5段階ではなく、**独自に変更した4択** です。
  標準版の Mini-IPIP でも、検証済みの日本語版でもなく、得点もそれらとは比べられません。
- IPIP の項目はパブリックドメインで、翻訳して使うことが認められています。
  - Mini-IPIP の採点キー: https://ipip.ori.org/MiniIPIPKey.htm
  - 利用許諾: https://ipip.ori.org/newPermission.htm
  - 採点方法: https://ipip.ori.org/newScoringInstructions.htm
- 原著: Donnellan, M. B., Oswald, F. L., Baird, B. M., & Lucas, R. E. (2006).
  The Mini-IPIP scales: Tiny-yet-effective measures of the Big Five factors of personality.
  *Psychological Assessment, 18*, 192–203.
- **この日本語訳と4択形式の信頼性・妥当性は未検証です。** 原著で報告された信頼性などの数値は
  英語版の5段階形式のもので、この形式の精度を示すものとして転載・表示しません。
- 各因子4問の短い尺度で、自己報告であり、翻訳による不確かさもあります。画面でもその旨を説明し、
  人口との比較や信頼区間は作りません。
- 開始前と結果の両方に次の文を表示します：
  「IPIPの項目を参考に、独自の日本語訳と4択形式に変更した自己理解用の簡易分析です。この形式の信頼性・妥当性は未検証です。医療上の診断ではありません。」

## プライバシーと技術的な約束

- すべてブラウザのメモリ内で処理。リロードやタブを閉じると消える（画面でも説明）
- `localStorage` / `sessionStorage` / IndexedDB / cookie / 外部 API / 分析 / 広告 / トラッキングを使わない
- 回答や結果を URL（クエリ・ハッシュ・履歴）に載せない
- 外部フォント・CDN を使わない。`dist/index.html` には `connect-src 'none'` などの CSP を付ける
- 描画は `createElement` と `textContent` のみ（`innerHTML` 不使用）。ESLint のルールで上記を機械的に禁止
- 確認ダイアログはブラウザの `confirm()` を使わず画面内に用意（Artifact 内でも動くように）
- キーボード操作、ラベル、画面切り替え時のフォーカス移動、`aria-live` 相当のエラー通知、
  色だけに頼らない選択表示（チェック記号・「選択中」の文字）、44px 以上のタップ領域、
  `prefers-reduced-motion` に対応

## 支援の使い方の3案について

POTEX の既存サービスの **組み合わせ方の例** です。新しい料金プランとして命名・販売するものではなく、
提供を確約するものでもありません。価格・予約 URL は未確認のため表示しません。

1. 個別伴走を中心に進める（目標設計・個別セッション・日常のフィードバック・習慣の記録）
2. 専門的な課題を解く支援を中心に進める（担当コーチとの課題整理・必要に応じた専門スポット相談・教材／テーマ別WS）
3. 学習と仲間の環境を活用して進める（教材・DeepWork・Discord・オンライン交流会／WS・必要に応じた個別支援）
